{% if key == 'apple' %}

Download the profile (.mobileconfig)

  1. iPhone or iPad: open Settings > Profile Downloaded. Mac: open System Settings > Privacy & Security > Profiles.
  2. Tap or click Install.{% if signed %} The profile is signed by the lab CA, so the device can show "Not Verified" before the CA is installed. This is expected for this lab.{% else %} The profile is not signed, so the device shows "Unsigned".{% endif %}
  3. When the device asks for a password, type your Wi-Fi password.
{% elif key == 'windows' %}

Download the setup script (.ps1)

  1. Right-click the file, then select Run with PowerShell.
  2. Windows shows a security warning for the "NIT Srinagar Lab CA". Make sure that the thumbprint is the SHA-1 value below, then click Yes.
  3. Connect to {{ s.ssid }}. Type the user name {{ s.uid }} and your password.

For administrators: the WLAN profile (.xml) only, for netsh wlan add profile. It needs the CA in the trusted root store first.

{% elif key == 'linux' %}

Download the setup script (.sh)

  1. Open a terminal and run bash nits-wifi-setup.sh from your download folder.
  2. Connect to {{ s.ssid }}. NetworkManager asks for your password.
{% elif key == 'chromeos' %}

Download the network file (.onc)

  1. Open chrome://network in the browser.
  2. Under Import ONC file, select the file.
  3. Connect to {{ s.ssid }} and type your password.
{% elif key == 'android' %}

Use the NIT Srinagar Wi-Fi app: it sets up the network for you. To set it up by hand, use the settings below and install the lab CA from the IT desk.
